# Arduino Uno LED Circuit (Wokwi)

A virtual circuit simulation controlling an LED using an Arduino Uno, a 220Ω resistor, and a breadboard in Wokwi.

## Components Used
* Arduino Uno
* Breadboard
* LED (Anode to E10, Cathode to E11)
* 220Ω Resistor (Pin D8 to A10)
* Jumper Wires

## How It Works
* digitalWrite(8, HIGH); sends power from pin D8 through the resistor to turn the LED *ON*.
* digitalWrite(8, LOW); cuts power to turn the LED *OFF*.
